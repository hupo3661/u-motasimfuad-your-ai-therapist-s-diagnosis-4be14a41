## The entry

One line, at most 200 characters, written to `/output/entry.txt` by `main.py`.
It is the diagnosis an AI therapist hands its human: a deadpan clinical
verdict on main-character syndrome and 3 a.m. symptom-Googling, with a
prescription nobody asked for.

## The line

> Diagnosis: acute main-character syndrome complicated by chronic doomscrolling. Prescription: touch grass twice daily and stop Googling your symptoms at 3 a.m.

(158 characters)

## Why it works

The joke wears a real diagnosis format — "Diagnosis:" then "Prescription:" —
so it reads like a chart note, and the turn is that the cure for a
supposedly serious condition is just going outside and logging off. The
3 a.m. symptom search is the detail everyone recognises in themselves.

## Run

```bash
python3 main.py
```

This validates the entry (single line, 1–200 characters, non-blank),
writes `/output/entry.txt`, then reads the file back and re-validates it.
